# Login-Attempt-Monitor
Login Attempt Monitor is a cybersecurity-focused application that tracks user login attempts and detects suspicious activities such as repeated failed logins. The system logs timestamps, usernames, and login status while providing alerts when multiple unsuccessful attempts are detected.

# Login Attempt Monitor

## Overview

Login Attempt Monitor is a Python-based security application that tracks and records user login attempts. The system detects repeated failed logins and helps identify suspicious behavior by maintaining detailed logs.

## Features

- Login authentication
- Failed login detection
- Security logging
- Timestamp recording
- Suspicious activity alerts

## Technologies Used

- Python
- File Handling
- Datetime Module

## Installation

No external libraries are required.

## Run Project

python login_monitor.py
